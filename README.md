

\# AI Lead Assistant



A lightweight Python project that classifies incoming customer requests.



\## Features



\- Classifies requests as sales, support, or general

\- Detects simple urgency keywords

\- Returns structured lead information

\- Includes automated unit tests

\- Uses Python's standard library



\## Requirements



\- Python 3.10 or newer



\## Run the application



```powershell

py src/main.py

```



\## Run tests



```powershell

py -m unittest discover -s tests -v

```



\## Current limitations



This version uses keyword-based rules. It does not call an AI model or connect to external services yet.
